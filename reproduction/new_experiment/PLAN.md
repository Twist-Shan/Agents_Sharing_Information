# Frozen review-response diagnostic experiment

This prospective experiment uses 32 blocks, four equally weighted whole-task wordings, three programmed partner policies, two delivery laws, two SAFE values, and two delivery-law encodings. The 24 task cells in each block each receive seven independent requests: unaided action U, rule diagnostic D1, action-probability diagnostic D2, expected-score diagnostic D3, and action aids A1/A2/A3. Total: 5,376 planned requests. Every wording/mapping/display-order/actor combination appears exactly once. No past action responses are reused. Seeds 19417/5939/8117 are unrelated to dates.

The original environment, observation, partner policy, and payoff paragraphs are preserved exactly from the archived original_protocol.py. The original full prompt already supplies the conditional probability of the partner's receipt. D2 therefore measures its conversion into the partner's JOIN probability rather than deriving a conditional receipt probability. A1 supplies that JOIN probability. A2 additionally supplies the JOIN payoff lottery. A3 additionally supplies expected scores. U and the aid arms share the same panel header, row order, location, and SAFE lottery; panel contents are nested, not token matched. The diagnostics ask separate questions without intermediate hints or a requested action. They can establish a difference between separately elicited task performances, not what an erroneous action internally understood.

Three primary comparisons, each equal-weighted over the 24 task cells and four wordings, are A1−U, A2−A1, and A3−A2 in expected-score accuracy. Unit of analysis is the 24-cell block mean of paired accuracy differences. Four wording strata have eight blocks each. Report approximate Welch-Satterthwaite intervals using Bonferroni over the three comparisons, together with bounded independent-block Hoeffding intervals. Pooling mapping/order/actor combinations within wording is explicitly part of the variance approximation; full32-way strata cannot support a variance estimate at this allocation. Zero empirical variance suppresses the normal interval rather than producing zero-width certainty. The conservative bounded interval remains. This modest allocation does not establish five-percentage-point equivalence.

All diagnosis and action rates are exported by response type, policy, law, wording, SAFE, and encoding, with fixed planned denominators. Numeric schema validity is independent of scientific correctness: finite wrong numbers, including probabilities outside [0,1], remain valid scientific errors. Booleans, nonnumeric strings, nonfinite values, missing keys, and extra keys fail the schema. The acquisition parser must reject duplicate/conflicting JSON keys or competing answers before passing ordinary dictionaries. Scoring uses absolute numerical tolerance 1e-8. Action codes must be X/Y with the fixed request-specific mapping. No response is retried because it is wrong.

Analysis requires the full frozen plan and two maps from planned ID to a parsed answer dictionary: first physical responses and final accepted responses. Unresolved IDs stay in denominators, and the exporter reports sharp binary completion bounds. Primary complete-data intervals are suppressed if any paired response for that contrast is unresolved. An observed-correct/planned rate is a lower completion bound when answers are unresolved; valid-only rates are separately labeled conditional. No comprehension result filters any action response. Every condition, including the secondary SAFE values, remains reported.

The parent runner separately controls the verified GPT-6 Luna none-thinking provider contract, uniform output cap, deterministic extraction, fixed unchanged operational retries, raw lineage, exact prior spend and concurrent cost reservations, identity/accounting gates, service pause rules, and the cumulative USD50 cap. These decisions must be archived before the first paid request. Science allocation, prompts, parser, and analysis cannot be tuned after responses are inspected. Budget/service/identity stops are operational; no result-based stopping, replacement, wording selection, or sample expansion is allowed. A provider policy rejection stops acquisition without stimulus rewriting. Missing outcomes are disclosed, not silently discarded.

Independent diagnostics, within-task aids, failures, uncertainty, and per-wording heterogeneity are all reportable. A useful aid is evidence of the effect of an explicit summary in this task; it is not a uniquely identified arithmetic, probability, attention, or social-reasoning mechanism. Different elicitation tasks may themselves change attention and difficulty. Outcomes from 32 fixed blocks describe this model/interface and stimulus mixture, not all language models or a population of possible wordings.

Reproduction (network-free): run `python protocol.py` to freeze the deterministic plan, `python verify.py` for synthetic tests, and `python analysis.py --first first_answers.json --final final_answers.json --output analysis.json` for retained answer maps. Required external analysis dependency: SciPy for Student-t quantiles. The protocol and truth scoring use only the Python standard library. No API call is performed by these files.
