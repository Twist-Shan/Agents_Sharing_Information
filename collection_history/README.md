# Historical collection implementation

These files preserve the original collection, recovery, extraction, and export implementations and their local Python dependencies. They are archival code, not the default reproduction entry point. The repository does not include old account preflights, credentials, complete historical run directories, or the abandoned Sonnet cohort. Some historical entry points require those run layouts and amendment locks and are not standalone commands.

Use `../reproduction/` for tested offline reproduction. The newer fixed diagnostic study has its complete implementation, scientific manifest, requests, responses, and documented recovery amendment in `../reproduction/new_experiment/`. Neither archived collection code nor its historical model/price configuration is a recommendation to launch a fresh paid experiment. A new run requires a new fixed allocation, verified endpoint and prices, and an explicit budget.
